# Ebisu 店务助手 / Ebisu Store Assistant

Installable web app (PWA) for Ebisu Life Store Tampa: barcode scanning for sales floor vs. backroom counts,
stock and recent sales lookup, reorder suggestions, and new items from the EBISU wholesale site.

- App: https://ebisutampa.github.io/ebisu-app/
- Data: Supabase (see `supabase-setup.sql`); only the signed-in store account can read or write.
- No purchase prices are stored in this app.
